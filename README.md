\# Python 第一章 程序设计基本方法 课后练习

> 课本第一章配套练习，熟悉Python基础开发环境、IPO思想、循环、输入输出、turtle简单绘图。



\## 练习内容

1.1 字符串拼接：input输入、format格式化输出

1.2 1\~N累加求和：for循环、range基础用法

1.3 九九乘法表：双层for循环，格式化对齐

1.4 阶乘累加：累乘+累加，理解循环变量更新

1.5 食材两两组合：双重循环+条件判断去同食材

1.6 幸运数字：random随机库、ord()字符编码

1.7 五角星绘图：turtle库、while循环绘图、填充

1.8 太阳花绘图：turtle库，循环旋转绘制图案



\## 学习心得

通过第一章的8个小程序练习，我初步熟悉了Python的开发环境，学会了运行代码、查看输出结果。

这些小程序覆盖了最基础的IPO程序思路：输入(Input)、处理(Process)、输出(Output)。

\- 前几道数值和字符串题目，让我理解了`input()`获取输入，`print()`输出，以及for/while循环的基本用法；

\- 九九乘法表让我体会到双层循环的嵌套逻辑，以及格式化输出对齐的技巧；

\- 阶乘求和练习，让我区分累乘和累加，明白循环里变量更新顺序很关键；

\- 食谱组合练习，学会双重循环遍历组合，用if条件过滤不需要的情况；

\- 幸运数字程序接触了random随机库、ord()获取字符编码，了解简单的字符处理；

\- turtle绘图两个程序非常有意思，直观看到代码控制图形，理解循环、角度、坐标的概念，感受到编程可视化的乐趣。



现阶段我暂时不用深究底层语法细节，重点感受：\*\*代码是告诉计算机一步步做事的指令\*\*，学会看懂程序流程、能够成功运行、看懂运行结果。

后续我会继续练习，巩固循环、分支基础，慢慢建立计算思维。
